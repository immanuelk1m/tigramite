기준 변형: **+O1+O2** · 측정일 2026-11-26 · baseline 커밋 `5ddcf48`, 전체 적용 = `8e0c390`

- 샘플: 노트북 `copper_causal_matching.ipynb`의 `fit_graph`를 그대로 복제해 실행.
  - **실제 창**: `02_casual/db/copper.parquet` → 노트북 cell-08/14/15 전처리 + CSV round trip, 2026-11-22에 끝나는 78주 창 1개 (변수 28개, Fortran 순서).
  - **합성 창**: seed 0 선형 VAR (변수 28개, 링크 45개, t(5) 노이즈, 4~7번 열 반올림), 첫 78행 1개.
  - 각 창에서 8개 실험 (PCMCI+/LPCMCI × tau_max 1·2 × B 자기시차 차단 여부), `ParCorrFast(significance="analytic")`, alpha 0.05.
- 실행: Python 3.12.12, numpy 2.5.5, scipy 1.18.1, BLAS 1스레드, 변형별 순차 실행 (Apple Silicon, P코어 4개).
- 변형 생성: `5ddcf48` + 최적화별 패치(`8e0c390` diff를 hunk 단위로 분리). 전체 패치 적용본이 `8e0c390`과 바이트 단위로 같은 것을 확인.
- 동일성: 모든 실험에서 graph 완전 일치 + val/p 차이 0 (기준 = `5ddcf48` 출력).
- 노이즈: 기준 변형 2회 측정 차이 = 실제 0.6%, 합성 0.2%. 이보다 작은 Δ는 측정 오차 범위.
- 시간 단위: 초(s). Δ = 기준 대비 변화, × = 기준 시간 / 변형 시간.
