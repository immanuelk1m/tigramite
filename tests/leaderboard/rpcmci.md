# Leaderboard · RPCMCI

기준 커밋은 `9cdba1343fd4763da72d2b04e9687c75d4318051`입니다. 단독 변형은 각각 기준 커밋에 적용했습니다.

- T는 튜토리얼의 500시점·3변수 합성 시계열입니다. `tau_max=1`, annealing 1회, 최적화 반복 상한 20입니다.
- M은 seed 43으로 생성한 160시점·8변수 합성 시계열입니다. `tau_max=2`, annealing 2회, annealing당 최적화 반복 1회입니다.
- R은 seed 28로 생성한 96시점·3변수 시계열입니다. 단일 regime과 `switch_thres=0`으로 동일 마스크가 반복되는 상황을 확인했습니다.
- RPCMCI seed는 43, 성능 측정은 `n_jobs=1`입니다. 별도 출력 비교에는 튜토리얼의 `n_jobs=2` 실행, 결측값과 표본 부족으로 `None`을 반환하는 사례, 동률 216건과 500시점 LP 1건을 포함했습니다.
- 측정 환경은 Intel Core i9-12900, Linux x86_64 WSL2, Python 3.13.12, NumPy 2.5.5, SciPy 1.18.1, scikit-learn 1.9.1, OR-Tools 9.15.6755, joblib 1.6.0입니다. BLAS는 1스레드로 제한했습니다.
- 각 변형은 워밍업 후 순서를 교대하며 10회 측정했습니다. 개선율은 같은 회차의 두 실행에서 계산한 `100 × (1 − 변형 시간 / 기준 시간)`의 중앙값입니다. CI는 해당 개선율의 95% 짝지은 부트스트랩 신뢰구간입니다.
